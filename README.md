# レッスンメモ

レッスン中にタスクをさっと書き留める箇条書きメモ。

- 開くと今月のページの一番下にカーソルがあり、すぐ入力できる
- **Enter** で次の項目へ（日本語変換中の Enter は無視）／行頭で **Backspace** すると前の項目とつながる
- 先頭の「・」をタップすると完了（✓）の切り替え
- **コピー** ボタンでその月のメモを日付ごとの箇条書きテキストでコピー。日付ごとの「この日をコピー」もあり
- 1ヶ月ごとにページを分け、‹ › で月を移動（月名タップで今月へ戻る）。メモは縦スクロールで読める
- **フォルダ**：上のタブの「＋」で作成。開いたフォルダには全部の月のメモが並び、そこで書いたメモはそのフォルダに入る
  - 行を選ぶと右に出る 📁 から、メモをフォルダに入れる／出す
  - 選択中のフォルダのタブ（または上の名前）をもう一度タップすると、名前の変更・削除（削除しても中のメモは残る）

データはブラウザ（localStorage）に自動保存されます。

## 端末間の同期（iPhone・iPad など）
右上の ☁ からメールアドレスとパスワードでログインすると、Firebase（Firestore）経由で同期されます。
- 1台目は「はじめて使う（登録）」、2台目からは同じメールアドレスで「ログイン」
- ログインすると、その端末にあったメモはアカウントのメモと合わさる（どちらも消えない）
- オフラインでも書け、つながったときに自動で送られる
- ☁ の点：緑＝同期済み／黄＝送信中・オフライン／赤＝未ログイン

データは `users/{uid}/items/{id}` に1項目ずつ、フォルダは `users/{uid}/folders/{id}` に保存（2台で同時に書いても上書きし合わない）。
読み書きできるのは本人だけ（`firestore.rules` を Firebase コンソールの Firestore → ルール に設定）。
Firebase の設定値は `firebase-config.js`。
